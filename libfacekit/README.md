# libfacekit

Reusable Android capture / session kit (`FaceRecognitionClient`, `CameraPreview`, `ModeAnalyzer`, `FaceJson`, …).

Pulled automatically when your app applies:

```gradle
apply from: 'https://raw.githubusercontent.com/identixia-IDV/FaceRecognition-LivenessDetection-Android/main/install.gradle'
```

Local sample builds use the `:libfacekit` module in this repo.
