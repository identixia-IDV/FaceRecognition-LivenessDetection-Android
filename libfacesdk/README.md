# libfacesdk

Android library module for the Face Recognition demo.

- Consumes `facerecognitionsdk.aar` (Java API + jniLibs). Model packs live in `databases/`.
- The sample app applies `install.gradle`, which uses this module when the AAR is already here.

Keep `facerecognitionsdk.aar` and `databases/` in this folder. `install.gradle` uses them when they are already here.
